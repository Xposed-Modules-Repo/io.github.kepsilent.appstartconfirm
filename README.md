# AppStartConfirm — Always Allow App-to-Jumps (ColorOS)

LSPosed 模块：恢复 ColorOS 应用间跳转确认框的「始终允许打开」复选框，真实生效。无界面、无设置、启用即生效，APK 仅 10.3KB。

Restores the "Always allow to open" checkbox in ColorOS app-jump confirmations — and it actually works. No UI, no settings, 10.3KB.
